HR Management System (Angular + GraphQL)

This project is an Angular-based HR Management System frontend that uses GraphQL APIs to manage employees, departments, attendance, and HR operations.

📖 About

An Angular HR management frontend application that uses GraphQL APIs to manage employees, attendance, and organizational data.

🚀 Features
Employee management
Department management
Attendance tracking
GraphQL API integration
Apollo Client integration
CRUD operations
Responsive UI
Modular Angular architecture
